《快乐文字》用户操作说明书
版本号：V1.0
第1章 软件概述
1.1 软件简介
本软件是一款适用于Android平台的本地文件管理应用，主要实现应用专属内部存储与内部共享存储指定目录下的TXT文件和图片文件浏览，TXT文件编辑，以及文件搜索、排序、文件夹压缩为ZIP、ZIP压缩包解压、文件分享等功能，为用户提供高效、便捷的本地文件管理体验。
1.2 软件功能
1. 文件浏览：支持查看应用专属内部存储与内部共享存储指定目录下的所有文件，支持多级目录遍历。
2. 文件编辑：支持TXT文本文件的打开、修改、保存操作；系统自动在TXT文件名中嵌入唯一字符标识以及最后更新时间戳，方便文件的整理溯源；支持对当前编辑文本内容执行撤销与恢复操作。
3. 文件搜索：支持在当前目录及子目录范围内，按文件夹名、文件名及TXT文件内容进行关键词检索，并展示匹配结果。
4. 文件排序：支持按类型、名称序号、首字母、更新时间多维度排序。
5. 压缩管理：支持文件夹压缩为ZIP、ZIP文件解压。
6. 文件管理：支持复制、剪切、粘贴、删除、重命名、分享等操作。
1.3 运行环境
1. 操作系统：Android 7.0及以上
2. 内存：1GB及以上
3. 存储：可用空间100MB以上

第3章 功能操作说明
3.1 主界面介绍
软件启动后进入主界面，界面布局如下：
1. 顶部区域：左上角为菜单弹出按钮，菜单内容随当前展示目录类型动态变化；中央为搜索输入框，框内以浅色提示文字显示当前文件夹目录基于主页根目录文件夹的序号标识（输入内容时提示文字自动消失，清空输入内容后重新显示）；搜索框左侧为搜索执行按钮。
2. 中部区域：为文件列表展示区域，用于显示当前目录下的文件与文件夹。黄色条目为文件夹，灰色为其他各类文件。
3. 底部区域：右下角为圆形加号按钮，支持在当前目录新建TXT文件。

3.2 菜单功能介绍
点击左上角菜单按钮唤起菜单面板，可切换应用内三大根目录。三大目录存储相互独立，功能与安全设计各有区分：
1. 主页目录为应用专属内部存储，用于存放用户核心重要文件，防止外部应用擅自读取、篡改或误删除。菜单支持从子目录快速返回主页根目录、新建文件夹、切换至回收站及中转站。
2. 回收站目录为应用专属内部存储，隔离存放已删除文件，避免被系统清理或外部访问，保障文件恢复安全。支持文件恢复与回收站清空操作，菜单可切换至主页目录、中转站，或一键清空回收站。
3. 中转站目录采用设备公共共享存储，作为本应用与设备其他文件的数据交互中转区域。首次进入将自动申请存储访问权限，授权后方可正常使用。本应用申请存储权限仅用于中转站目录的文件读取、写入、分享与中转交互，不会收集、上传任何用户个人隐私数据。菜单支持切换至主页、新建文件夹、跳转回收站；同时可将主页全部文件压缩为ZIP备份文件保存至中转站目录内，避免应用卸载造成数据丢失。

3.3 文件搜索
1. 点击界面顶部搜索输入框可唤起键盘。
2. 在搜索框内输入目标关键词。
3点击搜索按钮后进入搜索模式，系统将遍历当前目录及全部子目录，筛选出文件名或TXT文件内容包含输入框关键词的文件和文件夹，并展示检索结果。
4. 搜索功能自动忽略名称末尾带#的文件夹。用户可在不常用文件夹名称末尾添加#，以此缩小搜索范围、提升检索速度。
5. 搜索结果展示后，点击TXT文件和图片文件可浏览，同时页面底部将展示之前所点击文件的存储路径。该路径提示框会随点击浏览文件的切换自动更新，退出搜索模式后自动隐藏。点击路径提示区域，可快速跳转显示至该文件所在文件夹，并退出搜索模式。

3.4 文件浏览操作
1. 支持浏览应用三大根目录，包括主页目录、回收站目录、中转站目录，及其全部子目录下的文件与文件夹。
2. 点击文件夹条目，即可进入对应文件夹并展示内部内容。
3. 点击文件条目可直接打开对应文件；支持TXT、图片类文件在线浏览，暂不支持其他格式文件打开，保障程序运行安全。
4. 点击ZIP压缩文件条目，将弹出操作对话框，可选择是否将该压缩文件解压至当前目录。
5. 点击系统返回按钮，可退回上一级文件夹，也能从文件浏览页面直接回到文件所在文件夹。部分手机品牌还支持屏幕左边缘右滑的返回操作。

3.5 长按操作功能
在文件列表区域长按不同条目，将弹出对应操作按钮，具体功能如下：
1. 长按文件夹条目，弹出操作选项，支持文件夹重命名、复制、剪切、删除，以及将该文件夹及内部全部文件压缩为ZIP格式并保存至当前目录。
2. 长按文件条目（包含TXT、ZIP、图片等各类文件），弹出操作选项，支持文件重命名、复制、剪切、删除，同时可唤起Android系统分享面板，将文件分享至其他应用。
3. 点击复制或剪切按钮后，页面自动显示隐藏的粘贴按钮。用户可自由切换浏览其他文件夹，粘贴按钮将持续保留；进入目标目录后，点击粘贴按钮，即可将已复制或剪切的文件、文件夹粘贴至当前位置。粘贴操作执行完成后，粘贴按钮自动隐藏。

3.6 文件排序
1. 页面展示的全部文件与文件夹将自动执行排序。
2. 整体优先按类型分类排序：文件夹优先级最高，其次为ZIP文件、TXT文件与图片文件，其余类型文件排列在末尾。
3. 各类别内部排序规则：
（1）文件夹：优先依据名称序列号排序；序列号支持阿拉伯数字、中文数字，仅当文件名最前方的数字中或数字后面包含「.」「、」符号时，方可识别为有效序列号。无有效序列号的文件夹，按名称首字母或者汉字拼音首字母排序。
（2）TXT文件与图片文件混合排序，二者排序规则一致：优先按序列号排序；无序列号时，采用更新时间倒序，最新修改文件优先展示。
4. TXT文件与图片文件的时间排序，通过识别文件名末尾隐藏时间戳实现，条目展示时自动隐藏时间戳与文件后缀以外的冗余标识。新建、修改、移动、重命名文件时，系统自动更新文件名尾部时间戳。原生无时间戳的文件，首次更新将追加六位随机字符+时间戳作为唯一标识，用于文件全生命周期追踪，不受名称、内容修改影响；后续更新仅新增或替换第二条时间戳，严格控制文件尾部有效时间戳数量不超过两个。
3.7 TXT文件编辑
                      
图3-7 TXT文件编辑状态
1. 点击TXT文件即可进入编辑界面，同时支持文本浏览，可上下滑动查看完整文件内容。
2. 界面上方为文件名编辑区域，下方为文件内容编辑区域。点击对应区域可定位输入光标，并唤起输入键盘。
3. 界面右上角设有撤销与恢复按钮，按钮只在编辑状态下显示。点击撤销可回退至上一步编辑状态，点击恢复可撤销本次回退操作。
4. 退出编辑并返回上级目录时，系统自动保存文件。保存完成后弹出结果提示，展示文件新建或更新状态，提示弹窗将于一秒后自动关闭。
3.8 图片浏览
1. 点击图片文件，进入图片浏览界面。
2. 上下滑动屏幕，可快速切换当前文件夹内的上一张、下一张图片文件。
3. 支持双指缩放操作，双指外拉可放大图片局部区域，放大状态下单指滑动可拖动调整显示范围；双指内缩可缩小图片，当图片恢复原始尺寸后，可重新通过上下滑动切换图片。
3.9 页面记忆功能
1. 应用具备访问路径记忆能力，用户每次进入文件、文件夹时，系统自动留存浏览记录。
2. 重新启动应用时，将依据历史浏览记录，自动恢复至上次退出时所处的目录页面，延续上一次操作界面。
